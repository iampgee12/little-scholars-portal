PAYE Settings
Enabling the PAYE Engine will automatically calculate statutory deductions (PAYE Tax, Pension, NHIS, and NHF) on each salary based on the active PAYE configuration. You can still add non-statutory deductions (and benefits) via recurring payroll items, but statutory deductions will be auto-managed by the system.
%
Non-statutory deductions are capped so that net pay never falls below this percentage of gross pay. Default: 46.67% (Nigerian Labour Act — one-third rule). Set to 0 to disable the limit.
The account used as the payroll wallet / salary bank when posting disbursements to the expense ledger and General Ledger.
